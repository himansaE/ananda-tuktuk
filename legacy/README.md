# Embul Ambe Tuk-Tuk Tours

Static one-page website for a local tuk-tuk driver based in Embul Ambe near Dambulla, Sri Lanka.

## Launch Notes

- Replace `94770000000` in `script.js` with the real WhatsApp number.
- Replace the `AA` brand mark with the driver's real initials or name.
- Replace remote placeholder travel images with real driver and tuk-tuk photos when available.
- Open `index.html` directly in a browser, or serve the folder with any static web server.

## Verification

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\site-checks.ps1
```
